
# 📊 Netflix Dataset Visualization

## 📌 Project Overview

This project analyzes a Netflix dataset using **Python, Pandas, and Matplotlib**. The goal is to explore Netflix movies and TV shows and represent the data through different visualizations.

## 🛠️ Technologies Used

* Python
* Pandas
* Matplotlib
* CSV Dataset

## 📊 Visualizations

### 1. Movies vs TV Shows

A bar chart comparing the number of movies and TV shows.

### 2. Ratings Distribution

A pie chart showing the distribution of the most common Netflix ratings.

### 3. Releases by Year

A line plot showing the number of Netflix titles released over the years.

### 4. Movie Duration Distribution

A histogram showing the distribution of movie durations in minutes.

### 5. Release Year vs Movie Duration

A scatter plot showing the relationship between movie release year and duration.

## 📁 Dataset Columns

The dataset contains:

* `title` — Name of the movie or TV show
* `type` — Movie or TV Show
* `release_year` — Year of release
* `rating` — Content rating
* `country` — Country of production
* `duration` — Movie duration or number of seasons

## 🔍 Key Findings

* Movies and TV shows have different distributions in the dataset.
* Some content ratings occur more frequently than others.
* Netflix releases vary significantly across different years.
* Most movies fall within a particular duration range.
* The scatter plot helps visualize the relationship between release year and movie duration.
